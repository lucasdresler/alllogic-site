# Manual Operacional da AllLogic

O Manual Operacional da AllLogic (MOA) reúne os padrões e procedimentos operacionais utilizados pela empresa. Ele apoia a execução consistente das atividades e a evolução segura dos projetos.

## Documentos atuais

- [Fluxo Oficial de Desenvolvimento](fluxo-desenvolvimento.md): orienta mudanças relevantes desde o entendimento até a publicação.
- [Fluxo Oficial de Homologação Tecnológica](fluxo-homologacao.md): orienta a adoção ou atualização de tecnologias relevantes.
- [Homologações tecnológicas](homologacoes/): reúne os registros de homologações realizadas.

Novos procedimentos serão adicionados conforme a evolução da AllLogic.

> A tecnologia deve trabalhar para as pessoas.
